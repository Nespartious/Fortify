## Why Archive?

1. **Clean workspace** - Active sprints are easier to find in the main folder
2. **Historical reference** - Completed work is preserved for future reference
3. **Audit trail** - Shows what was done and when

---

## Archive Policy

A sprint is moved to archive when:
- All tasks in the sprint are marked complete
- The PR is merged (if applicable)
- The related documentation is updated
